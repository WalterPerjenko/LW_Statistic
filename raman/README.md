# Raman spectra — Lab01, sprint 1

Исследование положения, высоты и интегральной площади рамановской
полосы ацетона.

## Данные

Источник: https://doi.org/10.6084/m9.figshare.27931131

Описание: https://doi.org/10.1038/s41597-025-04848-6

Скачайте raman_spectra_api_compounds.csv и поместите его в папку
raman/data/. Исходный CSV в Git не включён.

## Запуск

Откройте Lab01_sprint1_Raman.ipynb в Jupyter или PyCharm.
Рабочая папка ядра должна быть raman.
Выполняйте ячейки сверху вниз.

Необходимые пакеты:
numpy, pandas, scipy, matplotlib, seaborn, openpyxl.

## Текущее состояние

Выполнены аудит данных, выбор полосы ацетона, локальная коррекция
фона, извлечение трёх признаков и индивидуальный анализ положения
и высоты пика.

Анализ площади и совместные статистические проверки ещё не завершены.
Генератор случайных чисел относится ко второму спринту.
