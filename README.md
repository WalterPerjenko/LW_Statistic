# 2 Спринт - генераторы
Для запуска кода второго спринта требуются следующие библиотеки
**`numpy`** 
* **`pandas`** 
* **`scipy`** 
* **`matplotlib` / `seaborn`** 
Что было сделано
Реализован генератор случайных чисел на базе квантильного преобразования.
* Описана математическая база метода (связь равномерного распределения на `[0, 1]` с обратной/квантильной функцией распределения и интерполяция по порядковым статистикам).
* Проведена проверка совпадения статистик и формы распределения реальных и сгенерированных данных (сравнение моментов, тест Колмогорова — Смирнова, графики плотности и Q-Q графики).
* Выполнены базовые проверки корректности работы генератора и оформлены выводы второго спринта.
