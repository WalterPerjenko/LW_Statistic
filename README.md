# AqSolB - спринты 1 и 2
AqSolB - открытый датасет растворимости химических соединений в воде
# 1 Спринт - — статистическое исследование
Для запуска кода первого спринта требуются следующие библиотеки
**`pandas`** 
* **`numpy`** 
* **`scipy`** 
* **`matplotlib`** 

* Загружен и подготовлен датасет **AqSolDB** , выделены целевые случайные величины .
* Обоснована стохастическая природа исследуемых величин.
* Проведён разведочный анализ данных  и рассчитаны статистики генеральной совокупности .
* Исследованы связи между величинами (матрицы корреляции Пирсона и Спирмана) и проверены статистические гипотезы.
* Проанализирована эмпирическая состоятельность выборочных оценок при росте объёма выборки `n` для двух схем отбора: с возвращением без возвращения .
