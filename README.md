# Навигация по репозиторию

Данная лабораторная разделена на три смысловые части, каждая из которых доступна в своей ветке: 
* Анализ (оба спринта) датасета AqSolB - основной датасет, предоставляемый для оценивания, на его основе также выполняли свою работу дизайнеры. Доступен в ветке main.
* Анализ (оба спринта) датасета рамановских спектров различных веществ - дополнительный датасет, обработанный с целью получения дополнительных баллов. Включает в себя несколько интересных методов на основе множества источников литературы, однако по двум из трех случайных переменных распределения выбраны эмпирическими, а по третей переменной распределение вышло биномиальным, а также между двумя переменными установлена высокая корреляция (что, возможно, не совсем интересно). Данный датасет не был включен в работу дизайнеров, поэтому выкладки кода могут показаться громоздкими. В связи с этим для лучшей ориентации в ноутбуке в соответсвующей папке создан дополнительный README файл. Доступен в ветке raman-sprint1 (несмотря на название, сделано оба спринта) или в ветке sprint-2---AqSolB __в папке raman__.
* Работа дизайнеров по датасету AqSolB - расположена в ветке KTvD-all-sprints.

Далее идёт краткое описание работы над датасетом AqSolB.

## AqSolB - спринты 1 и 2
AqSolB - открытый датасет растворимости химических соединений в воде
### 1 Спринт - — статистическое исследование
Для запуска кода первого спринта требуются следующие библиотеки
**`pandas`** 
* **`numpy`** 
* **`scipy`** 
* **`matplotlib`** 

* Загружен и подготовлен датасет **AqSolDB** , выделены целевые случайные величины .
* Обоснована стохастическая природа исследуемых величин.
* Проведён разведочный анализ данных  и рассчитаны статистики генеральной совокупности .
* Исследованы связи между величинами (матрицы корреляции Пирсона и Спирмана) и проверены статистические гипотезы.
* Проанализирована эмпирическая состоятельность выборочных оценок при росте объёма выборки `n` для двух схем отбора: с возвращением без возвращения .
